IT 230 Final Project Portfolio Reflection

Application Goals:
The goal of this application was to create a course registration system where students can register for classes, prevent duplicate registrations, check user input, and make sure the total credit hours do not go over the limit.

What I Did Well:
Something I did well was implementing the program logic and validation rules. I made sure the program prevented duplicate registrations and applied the credit hour limit. I also tested the program multiple times to make sure everything worked correctly.

Console vs WPF Design:
The console version used text-based input where users typed their selections, while the WPF version used a graphical interface with dropdown menus and buttons. The WPF version was more user-friendly and easier to navigate because it provided a clearer layout.

Debugging Approach:
I used Visual Studio to build the program, and I checked the error list to fix problems one at a time. After making changes, I ran the program again to make sure everything was correct.

Challenges:
One challenge I faced was making sure the program followed the registration rules and checked user input correctly. I solved this by adding validation checks and testing different situations until everything worked properly.
